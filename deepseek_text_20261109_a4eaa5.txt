RX (Receive): An onboard indicator LED that flashes when the Arduino is actively receiving data from a computer or another serial device via Digital Pin 0.

TX (Transmit): An onboard indicator LED that flashes when the Arduino is actively sending (transmitting) data to a computer or another serial device via Digital Pin 1.

L (Built-in LED): An onboard light-emitting diode hardwired directly to Digital Pin 13 on the Arduino board, used as a visual indicator to test code without external hardware.

Write this code to test your Arduino:

void setup() {

  // Set the built-in LED pin (Pin 13) as an OUTPUT

  pinMode(13, OUTPUT);

}

void loop() {

  digitalWrite(13, HIGH); // Turn the "L" LED ON

  delay(1000);            // Wait for 1 second (1000 milliseconds)

  digitalWrite(13, LOW);  // Turn the "L" LED OFF

  delay(1000);            // Wait for 1 second (1000 milliseconds)

}

.......................

How It Works:

pinMode(13, OUTPUT); configures Digital Pin 13 to supply power as an output interface.

digitalWrite(13, HIGH); delivers 5V to Digital Pin 13, illuminating the "L" LED.

delay(1000); pauses code execution for 1000 milliseconds (1 second).

digitalWrite(13, LOW); drops the voltage on Digital Pin 13 to 0V, turning the "L" LED off.

3. Introduction to Arduino

Arduino is an open-source electronics platform based on a programmable microcontroller. It is widely used in robotics, automation, electronics, and educational projects.

The Arduino board can receive information from sensors and other input devices, process this information according to a program, and control output devices such as LEDs, buzzers, and motors.

The main parts of the Arduino UNO include:

1. Microcontroller – executes the program.
2. Digital I/O pins – used for digital input and output.
3. Analog input pins – used to read analog signals.
4. USB port – used to program the Arduino and provide communication with a computer.
5. Power pins – provide 5 V, 3.3 V, and GND connections.
6. Reset button – restarts the program.
7. Power connector – can be used to supply external power.

Introduction to Robotics

Robotics is an engineering field that combines mechanical systems, electronics, sensors, actuators, and computer programming to design and control machines called robots.

1. A robot can be designed to:

- Sense its environment using sensors.
- Process information using a controller.
- Perform actions using motors or actuators.
- Operate automatically or according to programmed instructions.

2. A basic robotic system can be represented as:

Sensors -> Controller -> Actuators

For example, in an obstacle-avoiding robot:

- Ultrasonic sensor detects an obstacle.
- Arduino processes the distance information.
- DC motors move the robot in the appropriate direction.
